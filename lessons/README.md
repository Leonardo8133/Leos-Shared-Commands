# Lessons Index

Compact map of the current monolithic extension, split by app.

- `tasks.md` — command/task app structure and dependencies.
- `test-runner.md` — test discovery + execution app structure.
- `documentation-hub.md` — markdown browser app structure.
- `time-tracker.md` — timers + git automation app structure.
- `shared-core.md` — shared services currently coupling all apps.

Use these files as the baseline before extracting each app into its own extension.
